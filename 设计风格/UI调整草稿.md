# UI 调整草稿 v1

> 基调：保留粘土积木语言（粗黑描边 + 硬阴影 + 圆角），

## 三、信息层级（打断为主、怪物名辨识度）

1. **打断列 = 全表视觉锚点**
   - 标签：绿底深绿字、粗黑描边、方圆形（略大于其他标签）
   - 其他 6 种状态标签统一更淡、更小，衬托打断
2. **描述列**：文字 `#64748B` 保持、行高 1.6、宽 520px 上限，正文区留白充足
3. **怪物名**：
   - 主名 `#1E293B` 粗 800、字号 14px（比现在 13px 略大）
   - 英文副名小字保留
   - BOSS：绿底标签 + 深色怪名，不加 emoji（去掉"⭐"）
4. **技能名**：琥珀深 `#9A6A14` 加粗，链接 hover 变深石板色
